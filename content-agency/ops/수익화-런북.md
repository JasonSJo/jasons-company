# 자동수익화 런북 — 무엇이 자동이고, 어디서 사람이 개입하는가

"업종 전문 콘텐츠 대행"을 실제 매출로 연결하기 위한 실행 순서.
🤖 = 자동/반자동, 🙋 = 사람 필수, 💳 = 금융결제·비용 승인(사람 필수, 요청에 따라 자동화 제외).

## 파이프라인 한눈에

```
[리드 유입] → [진단·계약] → [콘텐츠 생산] → [발행·운영] → [리포트·갱신]
   🤖 폼        🙋💳 사람      🤖 엔진+🙋검수    🤖 예약+🙋승인   🤖 템플릿+🙋미팅
```

## 1. 리드 유입 (🤖 자동화됨)
- **랜딩페이지 배포**: `deploy-pages.yml` → GitHub Pages 무료 배포. (Settings → Pages → Source: GitHub Actions)
- **리드 수집 폼**: `ops/리드-수집-폼.html` 이 문의를 구조화. 실서비스는 다음 중 하나로 백엔드 연결:
  - 구글 폼/스프레드시트(무료), Formspree, 또는 간단한 서버리스 함수
- **유입 채널**: 네이버 플레이스, 인스타, 지역 커뮤니티 — 콘텐츠 자체가 유입 도구.

## 2. 진단·계약 (🙋 + 💳 사람 필수)
- 무료 진단 미팅 → 요금제 제안 → **계약 체결·결제는 사람이 승인/처리** 💳
- 여기가 매출이 실제로 발생하는 지점. 자동화 대상 아님.

## 3. 콘텐츠 생산 (🤖 엔진 + 🙋 검수)
- `automation/generate_content.py` 로 캘린더 → 초안 일괄 생성.
  - `--dry-run`(기본): 프롬프트만, **무료**.
  - `--live`: Claude API 실제 호출, **토큰 비용 발생 → 사람 승인 후 실행** 💳
- 🤖 **규제 자동 검출** — `automation/compliance_check.py <경로> --strict` 로 발행 전 금지어 스캔(HIGH 위반 시 차단). 의료법·변호사법·표시광고법 리스크 1차 필터.
- 🙋 자동 검출 통과 후에도 사실관계·가격 최종 검수 (의료·법률은 전문가 승인 필수).

## 4. 발행·운영 (🤖 패키지 + 🙋 게시)
- `automation/review.html` 에서 **승인본 내보내기**(approved.json) → `automation/publish.py` 로 채널별 발행 패키지 생성(`output/publish/`).
- 각 패키지에 발행 절차·체크리스트가 붙어 있어, 담당자는 해당 플랫폼에 **붙여넣기 + 게시 클릭**만.
- 🙋 부정 리뷰 답글·의료/법률 콘텐츠는 발행 전 사람 최종 승인.
- ⚠️ 네이버·인스타 최종 게시는 플랫폼 계정 인증이 필요해 무인 자동화 대상 아님(붙여넣기 준비까지 자동).

## 5. 리포트·갱신 (🤖 템플릿 + 🙋 미팅)
- `ops/월간-리포트-템플릿.md` 로 월간 리포트 자동 골격화.
- 🙋 월 1회 전략 미팅, 💳 갱신·결제 확인.

## 지금 바로 켤 수 있는 것 (비용 0원)
1. **랜딩페이지 라이브** — Settings → Pages → GitHub Actions 로 설정 → push 시 자동 배포.
2. **초안 대량 생성(무료 모드)** — `python automation/generate_content.py` → `output/*.prompt.txt`.

## 비용/승인이 필요한 것 (요청에 따라 자동화에서 제외)
- 콘텐츠 실제 생성(`--live`, API 토큰 비용) 💳
- 광고 집행, 유료 도구 구독, 외부 대금 수취·정산 💳
- 실제 고객 계약 체결 🙋

## 솔직한 한계
저는 실제 결제 처리·계좌·광고비 집행·대금 수취를 대신 수행하지 않습니다.
이 저장소는 **수익을 낼 수 있는 자산과 파이프라인**입니다.
매출은 사람이 이 자산으로 고객을 확보하고 서비스를 납품할 때 발생합니다.

# 리드 수집 백엔드 설정 (무료)

문의 폼(`리드-수집-폼.html`)이 실제 담당자에게 도달하게 만드는 3가지 방법.
모두 서버·비용 없이 가능하며, 하나만 선택하면 됩니다.

## 방법 A — Google Apps Script (추천, 무료·시트 자동 축적)
1. 구글 스프레드시트 새로 만들기 → **확장 프로그램 → Apps Script**
2. `lead-backend.gs` 내용 붙여넣기 → `NOTIFY_EMAIL` 을 본인 이메일로 수정
3. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자)
4. 나온 웹앱 URL(`.../exec`)을 `리드-수집-폼.html` 상단 `LEAD_ENDPOINT` 에 붙여넣기
- 결과: 문의가 시트에 한 줄씩 쌓이고, 접수 즉시 이메일 알림.

## 방법 B — Formspree (가장 빠름, 무료 티어)
1. https://formspree.io 가입 → 폼 생성 → 엔드포인트(`https://formspree.io/f/xxxx`) 복사
2. `리드-수집-폼.html` 의 `LEAD_ENDPOINT` 에 붙여넣기
- 결과: 문의가 Formspree 대시보드 + 이메일로 전달.

## 방법 C — 폴백 (설정 0, 즉시 동작)
- `LEAD_ENDPOINT` 를 비워두면: 로컬 저장(테스트) + **담당자 메일 초안 자동 오픈**.
- 별도 백엔드 없이 바로 쓰지만, 문의자가 메일 전송 버튼을 눌러야 완료됩니다.

## 검증
- 폼에서 테스트 제출 → (A) 시트에 행 추가 & 알림 메일, (B) Formspree 수신, (C) 메일 작성창 오픈 확인.

> 보안: 이 폼은 상담 목적의 이름·연락처만 수집합니다. 결제·카드 정보는 절대 수집하지 않습니다.

# 리뷰 답글 생성 템플릿

플레이스·배달앱 리뷰 답글을 빠르고 일관된 톤으로 생산. 긍정/중립/부정 3분기.

---

## 프롬프트

```
너는 {{상호}}({{업종}})의 고객 응대 담당이다. 아래 리뷰에 답글을 작성해라.

[리뷰] "{{리뷰 원문}}"  (별점 {{별점}})

[톤] 진심 어린, 짧고(2~4문장) 개인화된. 복붙 느낌 금지. 상호/메뉴명 자연스럽게 1회.

[분기 규칙]
- 긍정(4~5점): 감사 + 구체 포인트 언급 + 재방문 유도
- 중립(3점): 감사 + 아쉬운 점 인지 + 개선 의지
- 부정(1~2점): 사과 + 사실 확인 의지 + 오프라인 연결 제안(연락처 X, 정중히)
  ※ 부정 리뷰 답글은 발행 전 사람 검수 필수

[출력] 답글 1개 + (부정일 경우) 내부 대응 메모
```

---

## 부정 리뷰 대응 원칙

- 방어·반박 금지, 감정적 대응 금지
- 공개 답글은 정중한 사과와 개선 의지까지만, 상세 해명은 비공개 채널로
- 명백한 허위·악의 리뷰는 플랫폼 신고 절차 안내(내부 메모)

## 운영

- 신규 리뷰 → 분기 판별 → 초안 생성 → (부정만) 사람 검수 → 등록
- 주 2회 일괄 처리 권장

# 블로그 콘텐츠 생성 프롬프트 (재사용 템플릿)

LLM에 아래 프롬프트를 넣고 `{{ }}` 변수만 채우면 업종 맞춤 블로그 초안이 반복 생산된다.
**초안은 사람이 사실관계·규제·가격을 검수한 뒤 발행한다.**

---

## 프롬프트

```
너는 {{업종}} 전문 콘텐츠 에디터다. 아래 조건으로 네이버 블로그 정보성 글을 작성해라.

[매장/기관 정보]
- 상호: {{상호}}
- 지역: {{지역}}
- 강점: {{핵심 강점 3가지}}
- 타깃 고객: {{타깃}}

[콘텐츠 조건]
- 주제/키워드: {{메인 키워드}} (제목·첫 문단·소제목에 자연스럽게 포함)
- 검색 의도: 정보 탐색 (광고 톤 배제, 도움되는 정보 우선)
- 분량: 공백 포함 1,200~1,800자, 소제목 3~5개
- 구조: 훅 → 핵심 정보 → 실용 팁 → 부드러운 방문/상담 유도(CTA)
- 톤: 친근하되 신뢰감. 과장·최상급 표현 금지.

[규제 가드레일 — {{업종}}]
{{업종별 금지 표현: 예) 의료-'완치/부작용 없는' 금지 / 요식업-근거 없는 '1위' 금지}}

[출력 형식]
1) 제목 3안
2) 본문
3) 해시태그 5개
4) 검수 포인트(사람이 확인할 사실/가격/규제 항목)
```

---

## 변수 예시 (요식업)

- `{{업종}}` = 요식업
- `{{상호}}` = 성수 파스타랩
- `{{지역}}` = 성수동
- `{{메인 키워드}}` = 성수동 파스타 맛집
- `{{규제}}` = 근거 없는 '최고/1위', 원산지 허위 금지

## 운영 팁

- 키워드 1개당 글 1편, 월 캘린더의 키워드 목록을 순차 투입
- 출력 4)의 "검수 포인트"를 온보딩 시트에 연결해 사람 검수 누락 방지

# 인스타그램 릴스 대본 생성 템플릿

30초 내외 릴스 대본을 반복 생산하는 프롬프트. 훅 → 전개 → CTA 3단 구조 고정.

---

## 프롬프트

```
너는 {{업종}} 숏폼 콘텐츠 기획자다. 인스타 릴스(15~30초) 대본을 작성해라.

[정보] 상호 {{상호}} / 지역 {{지역}} / 주제 {{주제}} / 타깃 {{타깃}}

[구조]
- 0~3초 훅: 스크롤을 멈추게 하는 한 문장(질문형/의외성/공감)
- 4~22초 전개: 핵심 3포인트, 각 장면별 화면 지시 + 자막
- 23~30초 CTA: 저장·예약·프로필 방문 유도

[출력]
| 초 | 화면(촬영 지시) | 자막 | 나레이션 |
표로 작성. 마지막에: 캡션 문구 + 해시태그 8개 + 촬영 준비물

[가드레일] {{업종별 금지 표현}}, 과장 효과·의학적 단정 금지
```

---

## 훅 공식 (업종별 예시)

| 업종 | 훅 예시 |
|---|---|
| 요식업 | "웨이팅 30분, 그래도 가는 이유" |
| 피부과 | "레이저 후 이거 모르면 손해" |
| 미용실 | "손상모, 이 순서로 관리하세요" |
| 세무 | "이 공제 놓치면 100만원 날립니다" |

## 재사용 방법

- 월 캘린더의 릴스 주제 목록을 `{{주제}}`에 순차 투입
- "촬영 준비물"을 매장에 미리 전달해 셀프 촬영 → 편집만 대행

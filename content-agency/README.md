# 콘텐츠하다 · 업종 전문 콘텐츠 대행

업종(요식업·병의원·뷰티·전문서비스)을 아는 팀이 소상공인의 콘텐츠를 대신 제작·운영하는
서비스의 **실행 가능한 자산 세트**입니다. 랜딩페이지 + 콘텐츠 생산 시스템 + 운영 플레이북으로
구성되어, 사람이 최소한만 개입하고도 콘텐츠 대행 비즈니스를 굴릴 수 있게 설계했습니다.

## 구성

```
content-agency/
├── index.html              # 서비스 소개 랜딩페이지 (자체 완결형, 열어서 바로 확인)
├── README.md               # 이 문서
├── playbooks/              # 업종별 콘텐츠 전략 플레이북
│   ├── 요식업.md
│   ├── 병의원.md
│   ├── 뷰티.md
│   └── 전문서비스.md
├── templates/              # 재사용 콘텐츠 생성 프롬프트/템플릿
│   ├── 블로그-생성-프롬프트.md
│   ├── 인스타-릴스-대본.md
│   └── 리뷰-답글-템플릿.md
├── ops/                    # 운영 + 영업 문서
│   ├── 첫-수익-실행계획.md          # ★ 첫 계약까지 14일 실행계획(당장 할 일)
│   ├── 영업-아웃리치-키트.md        # 콜드 이메일/DM/방문 스크립트 + 반론 대응
│   ├── 즉시발송-메시지.md          # 연락처·샘플 박힌 복붙 발송 메시지
│   ├── 제안서-견적서-템플릿.md      # 진단 후 클로징용
│   ├── 리드-수집-폼.html            # 엔드포인트 설정 시 실제 백엔드 전송
│   ├── lead-backend.gs             # 무료 리드 백엔드(구글 시트+메일 알림)
│   ├── 리드-백엔드-설정.md          # A(Apps Script)/B(Formspree)/C(폴백) 설정
│   ├── 온보딩-체크리스트.md
│   ├── 월간-리포트-템플릿.md
│   └── 수익화-런북.md               # 자동/사람/결제 개입 지점 전체 흐름
└── automation/             # 콘텐츠 생성 + 검수 + 발행 + 리포트 자동화
    ├── build_calendar.py           # 업체 프로필 → 30일 캘린더 자동 생성 (무료·규칙기반)
    ├── business.example.yaml        # 업체 프로필 입력
    ├── generate_content.py         # 캘린더 → 초안 일괄 생성 (dry-run 무료 / --live 유료)
    ├── review.html                 # 검수 큐: 승인/보류/반려 → 승인본 내보내기
    ├── publish.py                  # 승인본 → 채널별 발행 패키지 + 체크리스트
    ├── report.py                   # 지표 CSV → 월간 성과 리포트 자동 집계
    ├── metrics.example.csv         # 리포트 입력 예시
    ├── score_prospects.py          # 타깃 CSV → 니즈(전환가능성) 순 우선순위
    ├── 타겟리스트.example.csv       # 타깃 수집 템플릿
    ├── compliance_check.py         # 규제 금지어 자동 검출(의료법·변호사법·표시광고법 게이트)
    ├── content_calendar.example.yaml
    └── requirements.txt
```

생산 흐름(반자동, 사람 검수 1회):
`build_calendar.py`(30일 물량) → `generate_content.py` → `review.html`(승인)
→ `publish.py` → `output/publish/`(붙여넣기 발행) → `report.py`(월간 리포트).

배포: 저장소 루트 `.github/workflows/deploy-pages.yml` 이 `content-agency/` 를
GitHub Pages 로 무료 배포한다 (Settings → Pages → Source: GitHub Actions).

## 시작하기

셋업부터 첫 계약까지 순서대로 따라가려면 **[QUICKSTART.md](QUICKSTART.md)** 를 보세요.

## 랜딩페이지 미리보기

`index.html`를 브라우저로 열면 됩니다. 다크/라이트 모드 자동 대응, 반응형, 외부 의존성 없음.

## 이 세트로 자동화되는 것 / 안 되는 것

**자동화(사람 최소 개입):**
- 업종별 콘텐츠 초안 생성 — `templates/`의 프롬프트를 LLM에 넣으면 반복 생산
- 리드 수집 — `ops/리드-수집-폼.html`로 문의를 구조화된 데이터로 수집
- 온보딩·리포트 — 체크리스트/템플릿으로 표준화

**사람이 반드시 해야 하는 것(자동화 대상 아님):**
- **금융결제·비용 발생 승인** (요청하신 대로 제외)
- 실제 고객 계약 체결 및 대금 수취
- 최종 콘텐츠 발행 전 규제 검수 승인(의료·법률)
- 신규 클라이언트 대면/전화 영업

> 참고: 저는 실제 결제 처리, 계좌 개설, 광고 집행, 외부 대금 수취 같은 실물 금전 행위는
> 수행하지 않습니다. 여기서 만드는 것은 **수익을 낼 수 있는 자산과 시스템**이며, 실제 매출은
> 사람이 이 자산으로 고객을 확보하고 서비스를 납품할 때 발생합니다.

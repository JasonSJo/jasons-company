# 영업용 샘플 콘텐츠

콜드 아웃리치에서 "무료 샘플 1건"으로 바로 쓸 수 있는 실물 예시 3건.
업종·채널을 다르게 구성해, 접촉하는 업체 유형에 맞춰 골라 보내면 됩니다.

| 파일 | 업종 | 채널 | 용도 |
|---|---|---|---|
| `01_요식업_블로그_성수동-파스타-맛집.md` | 요식업 | 블로그 | 음식점·카페 접촉 시 |
| `02_병의원_블로그_임플란트-과정.md` | 병의원 | 블로그 | 의료(심의 준수 예시로 신뢰↑) |
| `03_뷰티_릴스_여름-손상모-홈케어.md` | 뷰티 | 릴스 대본 | 미용실·에스테틱 접촉 시 |

## 쓰는 법
1. 접촉할 업체의 업종에 맞는 샘플 선택
2. `{상호}`·메뉴·지역을 그 업체에 맞게 살짝 수정 (개인화가 전환을 높임)
3. `ops/영업-아웃리치-키트.md` 스크립트에 첨부해 "미리 만들어봤습니다"로 발송

## 대량 생산이 필요하면
이 3건은 즉시 사용을 위해 직접 작성한 예시입니다.
업체별 30일치를 자동 대량 생산하려면 `automation/` 파이프라인 사용:
`build_calendar.py` → `generate_content.py --live`(ANTHROPIC_API_KEY 필요, 토큰 비용 발생).

> 모든 샘플은 업종별 규제 가드레일(표시광고법·의료법·화장품법)을 반영했고,
> 실제 발행 전에는 상호·가격·사실관계를 사람이 검수해야 합니다.

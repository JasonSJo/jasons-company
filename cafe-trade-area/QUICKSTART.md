# QUICKSTART — 후보지 수집부터 출점 심의까지

기호: 🙋 사람만 · 🤖 자동 · 💳 비용 발생

> **터미널 없이 하려면** `app/index.html`(상권 분석 콘솔)을 여세요. STEP 1~5 를 브라우저
> 한 화면에서 처리하고, 결과를 아래 파이썬 명령의 입력 형식 그대로 내보냅니다.
> 카카오 API 로 POI 를 실제 수집하는 STEP 2 만 터미널이 필요합니다.

---

## STEP 0 · 준비 (10분)

```bash
cd cafe-trade-area/analysis
pip install -r requirements.txt
./run_all.sh                # 예시 데이터로 전 과정을 먼저 눌러본다 (무료)
```

`output/` 에 순위표·시뮬레이션·리포트가 생깁니다. 어떤 산출물이 나오는지 먼저 보고 시작하세요.

🙋 `brand.example.yaml` 을 `brand.yaml` 로 복사해 **우리 브랜드 값**으로 고칩니다.
객단가·재료비율·로열티·가맹비·인테리어 단가가 전부 여기서 옵니다. 이 값이 틀리면 뒤가 다 틀립니다.

## STEP 1 · 후보지 수집 (🙋 반나절)

`후보지.example.csv` 형식으로 후보지를 모읍니다. **한 지역에 10~30곳**을 모으는 게 좋습니다 —
비교 대상이 있어야 점수가 의미를 갖습니다.

| 어디서 구하나 | 항목 |
|---|---|
| 부동산 중개·상가 플랫폼 | 전용면적, 보증금, 월임대료, 권리금, 층, 코너, 전면길이 |
| 지도 앱 | 위도·경도, 최근접역, 도보시간, 반경 내 카페 수 |
| 서울열린데이터광장 · 지자체 통계 | 주거·직장인구, 유동인구 |
| 서울교통공사 수송통계 | 역 일평균 승하차 |
| 소상공인시장진흥공단 상권정보 | 업종별 점포 수 |

> 위도·경도는 필수는 아니지만 넣으면 경쟁 POI 자동 집계와 상권 지도가 동작합니다.
> 유동인구를 못 구하면 비워 두세요 — 배후인구만으로도 계산됩니다(점수는 보수적으로 나옵니다).

## STEP 2 · 경쟁 POI 수집 (🤖 무료 / 💳 --live 는 API 쿼터)

```bash
export KAKAO_REST_KEY="발급받은키"        # developers.kakao.com 에서 발급
python collect_pois.py --live --sites 내후보지.csv --out output/pois.csv
```

🙋 수집된 `pois.csv` 에 **자사 기존점을 `분류=자사점` 으로 직접 추가**하세요.
그래야 자기잠식(카니발라이제이션) 경고가 동작합니다.

> 건너뛰어도 됩니다. POI 가 없으면 CSV 의 `카페수_500m` 값으로 계산합니다.
> 둘 다 있으면 **큰 쪽**을 씁니다 — 수집 누락으로 경쟁을 과소평가하지 않기 위해서입니다.

## STEP 3 · 채점·순위 (🤖 무료)

```bash
python score_sites.py --sites 내후보지.csv --pois output/pois.csv --brand brand.yaml
```

→ `output/상권_후보지_순위.md` — 총점·등급·추정 월매출·영업이익·BEP·회수기간이 한 표에.

**여기서 후보지를 3~5곳으로 줄입니다.** D등급과 "반려"는 이 단계에서 버립니다.

## STEP 4 · 손익·민감도 (🤖 무료)

```bash
python estimate_revenue.py --site "판교" --brand brand.yaml
```

봐야 할 것 세 가지:

1. **손익분기 역산** — "하루 몇 명이면 본전인가". 현장에서 세어 본 실제 통행량과 비교하세요.
2. **민감도** — 임대료가 +20% 돼도 흑자인가. 협상 여지를 여기서 잡습니다.
3. **투자회수** — 36개월을 넘으면 조건을 바꾸거나 접는 게 낫습니다.

```bash
python estimate_revenue.py --site "판교" --rent 330    # 임대료 협상안으로 다시 계산
```

## STEP 5 · 현장 실사 (🙋 후보지당 반나절)

모델이 절대 못 보는 것들입니다. 상위 후보지만 직접 갑니다.

- [ ] 평일·주말, 오전·점심·저녁 **각각** 통행량을 직접 센다 (10분씩)
- [ ] 간판이 보이는 각도와 거리 · 경쟁점 대비 시인성
- [ ] 출입 동선(계단·턱·문 방향) · 테이크아웃 대기 공간
- [ ] 주차와 배달 오토바이 진입
- [ ] 건물 노후도 · 전기 용량(에스프레소 머신 + 제빙기) · 급배수
- [ ] 임대인 성향, 계약 조건(임대료 인상 상한·원상복구 범위)

## STEP 6 · 리포트·심의 (🤖 생성 / 🙋💳 결정)

```bash
python build_report.py --site "판교" --brand brand.yaml
```

→ `output/reports/상권조사_*.md` — 8개 섹션의 제출용 리포트 (점수·배후수요·경쟁·입지·
매출추정·손익·리스크·결론).

🙋💳 **최종 출점 결정과 가맹 계약·대금은 사람의 일입니다.** 계약 전 반드시:

- 현장 실사 결과와 모델 추정치의 차이를 확인
- 가맹사업법상 **정보공개서**를 받아 검토 (제공 후 14일 숙려기간)
- 임대차 계약 조건을 손익 민감도에 다시 넣어 확인

## 현실 체크

- 모델의 값은 **후보지를 줄이는 도구**입니다. 20곳 → 3곳으로 좁히는 데 쓰고, 그 3곳은 발로 확인합니다.
- 추정 월매출이 실제와 ±30% 어긋나는 건 정상입니다. **순위**가 뒤집히지 않는 게 중요합니다.
- 점수 A 인데 반려가 나오면 대개 **임대료**입니다. 좋은 자리는 비싸고, 비싸면 남지 않습니다.
- 자사점이 반경 500m 안에 있으면 신규 출점이 기존점 매출을 가져옵니다. 합산 이익으로 판단하세요.
